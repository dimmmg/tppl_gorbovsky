## 1. Обработка изображений в реальном времени
- Парадигма: императивная и параллельная (последовательное выполнение инструкций и распределение вычислений на ядра процессора или GPU) 
- Язык: C++
- Почему: поток данных очень большой (более 3 ГБ/с), поэтому критически важна максимальная скорость обработки. C++ позволяет управлять памятью вручную без пауз сборщика мусора и оптимизировать код под конкретное железо

## 2. ML-сервис прогноза погоды
- Парадигма: объектно-ориентированная и декларативная (описание логики через готовые абстракции и экосистему библиотек) 
- Язык: Python
- Почему: MVP нужно запустить очень быстро. Python идеален для быстрого прототипирования благодаря огромному количеству готовых ML-библиотек (scikit-learn, pandas, PyTorch), что избавляет от необходимости писать сложные алгоритмы с нуля

## 3. UI торгового терминала
- Парадигма: реактивная и компонентно-ориентированная (интерфейс разделен на виджеты, которые автоматически перерисовываются при изменении данных)
- Язык: TypeScript
- Почему: нужно отображать более 50 виджетов с данными из разных источников (WebSocket, REST) с откликом менее 16 мс. Реактивный подход избавляет от ручного обновления DOM, а статическая типизация в TypeScript защищает от ошибок в сложной логике взаимодействия между компонентами

## 4. Прошивка для датчика температуры
- Парадигма: процедурная и императивная низкоуровневая (прямые инструкции процессору и работа с портами ввода-вывода)
- Язык: C
- Почему: у микроконтроллера жесткие ограничения по памяти (32 КБ RAM) и требования к энергоэффективности. Язык С не создает лишних накладных расходов, дает прямой доступ к регистрам железа и гарантирует детерминированное время отклика
